# MoonVine

A rewrite from scratch challenge for my iconic discord music bot ByteBlaze

THIS DISCORD MUSIC BOT IS UNDER VERY HEAVY DEVELOPMENT!!

## Requirements

- V-Lang Compiler, see <https://vlang.io/>

## How to

### Compile

```sh
v -prod -cflags "-O3 -march=native -mtune=native" .
```

### Test run

```sh
v run .
```
